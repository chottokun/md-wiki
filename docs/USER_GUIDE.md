# md-wiki ユーザーガイド

本システムは、LLMを活用して専門知識を「構造化されたWiki」として蓄積・管理するためのパーソナル・ナレッジベースです。

---

## 🚀 基本ワークフロー (三段階モデル)

### 1. 投入 (Ingest)
PDF、Markdown、テキストなどの一次資料を読み込ませます。
```powershell
uv run python main.py _raw/example.pdf
```
- **何が起きるか**: 記事が作成され、`wiki/` 直下に保存されます。この時、プロパティには `tags: [未審査]` が付与されます。
- **ヒント**: 人間による確認をスキップして自動承認したい場合は `--yes` (または `-y`) を付けてください。

### 2. 審査 (Review)
Obsidian で生成されたページを確認します。
- 内容が正しければ、**`未審査` タグを削除** してください。
- 修正したい箇所があれば自由に編集して構いません。

### 3. 反映 (Sync)
審査が終わった知識を検索エンジン（Qdrant）に登録し、Gitに保存します。
```powershell
uv run python main.py --sync
```
- **注意**: デフォルトでは `未審査` タグが付いたままのページは、検索対象になりません。
- **強制登録**: `未審査` タグが付いたままのページも強制的にインデックスに含めたい場合は、`--force` (または `-f`) を付けてください。

## 🛠️ 自律メンテナンスと拡張

### 知識の自動拡充 (Lint)
Wiki内のリンクはあるが実体がないページ（Red-link）を見つけ、AIが自動で執筆します。
```powershell
uv run python main.py --lint
```

### 手動編集の洗練 (Refine)
あなたが手動で大幅に書き換えたページを、AIに整形・洗練させることができます。
```powershell
uv run python main.py "ページ名" --refine
```

### 全件再構築 (Rebuild)
モデルをアップグレードした際や、全体をクリーンに作り直したい時に使用します。
```powershell
uv run python auto_rebuild.py
```
- **仕組み**: `wiki/` 内のデータを一度クリアし、`_raw/` 内の全PDFから最新の品質基準でWikiを再生成します。

## 🎨 閲覧と活用のコツ

- **Obsidian グラフビュー**: `Ctrl+G` で知識の繋がりを視覚化できます。未審査のノート（赤い点）が、承認によって青いネットワークに組み込まれていく様子を確認できます。
- **マルチデバイス**: `wiki/` フォルダを iCloud や Syncthing で同期すれば、スマホから閲覧・審査することも可能です。
- **AI共同編集**: AIが書いた `description`（概要/旧要約）が不十分だと感じたら、一行書き換えるだけで、次回の更新時にAIがそのトーンを学習して追従します。

## 🌐 標準リンク変換とローカルWebサイト化 (MkDocs)

Obsidian 独自の二重ブラケット構文を標準リンクへ変換し、美観に優れたドキュメントWebサイトをローカルで閲覧できます。

### 1. 二重ブラケットの標準リンク変換
Obsidian 独自の `[[リンク名]]` 構文を標準の相対マークダウンリンクへ変換し、別のフォルダ（`dist/wiki/`）へエクスポートします。（元の `wiki/` フォルダは破壊されません）
```powershell
uv run python convert_links.py
```
- **プレビュー**: 実際に書き換えを行わずに変換されるリンク数を確認したい場合は `--dry-run` を指定します。

### 2. ローカルドキュメントサイトのビルドと起動
マテリアルテーマ（`mkdocs-material`）をベースにしたモダンな検索機能付きWebドキュメントサイトを起動します。
```powershell
# 1. 静的HTMLのビルド (site/ ディレクトリへ出力)
uv run mkdocs build

# 2. ローカルプレビューサーバーの起動
uv run mkdocs serve
```
サーバー起動後、ブラウザで `http://127.0.0.1:8000` にアクセスすると、ダークモード/ライトモードの動的切り替えや、超高速なローカル検索機能を備えた高品質なWikiサイトを閲覧できます。
*(※セキュリティの観点から、インターネット上への自動公開（GitHub Actions等）の設定は含めていません。ローカルでのみ安全に動作します)*

## ⚠️ トラブルシューティング
- **検索にヒットしない**: `main.py --sync` を忘れていませんか？ または、`未審査` タグが残っていませんか？
- **YAMLエラー**: プロパティを手動編集して壊してしまった場合、`main.py --lint` を実行すればPydanticバリデータが自動で修復を試みます。
